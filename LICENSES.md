## Dependencies and External Components

The Panaroma Workspace Switcher interacts with several open-source components and frameworks:

* **Hyprland**  
  License: BSD-3-Clause  
  Role: Wayland compositor and window management dispatching.

* **Quickshell**  
  License: LGPL-3.0-or-later / GPL-3.0  
  Role: QtQuick desktop layer shell engine for rendering the workspace ring.

* **Grim**  
  License: MIT  
  Role: Screen capture utility used for snapshot generation.

* **Qt6 / QtQuick**  
  License: LGPL-3.0 / GPL-3.0  
  Role: Graphic toolkit and shader integration.

* **Python**  
  License: Python Software Foundation (PSF) License  
  Role: Execution runtime for session management and controller tooling.
